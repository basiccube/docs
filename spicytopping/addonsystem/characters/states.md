# Custom States

You can add 10 custom states to your character by placing code files in your character's "states" folder and naming them custom1 through 10, for example: `(addon folder)\characters\(character folder)\states\custom5.gml`.  
Once you've done that, you need to be able to set the player to this state elsewhere, you could use a character event for instance to do so. You can use states.custom1 and so on in the code for referencing your custom state.

See [Constants](spicytopping/constants) for the entire state list.
