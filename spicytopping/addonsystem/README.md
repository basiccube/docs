# Addon System

The addon system in Spicy Topping allows you to add extra functionality into the mod using so-called "addons". With it, you can add new objects, or even characters without too much effort.

Addons are loaded from an "addons" folder, located in Spicy Topping's AppData directory (%appdata%\PizzaTower_SE\addons). Each addon has its own separate folder.

Currently, it is incredibly incomplete, and is not very usable right now. As such, everything here is subject to change.

One way it's incomplete is that there is only one way to enable/disable addons right now, that being the Addon Editor. To access it, open the debug console and type in `showgametools`. This opens up the "Game Tools" window, which should have the Addon Editor. From there you can select an addon and then check "Enabled" to enable the addon.
